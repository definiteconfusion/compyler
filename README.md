## Overview

Transpiler to functionally / logically convert Python to Rust. Still in early development, but its still kind of a neat toy for now

## Currently Supported Features

### Logic Stuctures

- Loops

  - `For`

- Conditionals

  - `if`
  - `elif`

- Boolean Operations

  - `==`
  - `!=`
  - `>`
  - `<`
  - `>=`
  - `<=`

- Binary Operations

  - `+`
  - `-`
  - `+=`
  - `-=`
  - `*`
  - `/`
  - `//`
  - `%`

- Global Functions

  - `range()`
  - `append()`
  - `print()`

- Variables (mutability is assigned automatically if required, requirement is detected automatically upon value reassignment)
